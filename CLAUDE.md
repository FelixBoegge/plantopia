# Project instructions

## ponytail is installed but off

`ponytail` (project scope) is installed with `PONYTAIL_DEFAULT_MODE=off`, so its
SessionStart hook injects nothing. Its skills and `/ponytail` commands stay
available on demand.

If you do invoke ponytail, **superpowers still wins** on process — brainstorming
before creative work, a written plan for multi-step tasks, TDD, verification
before claiming completion. Ponytail's brevity rules never justify skipping a
superpowers workflow, and its terse-output rule never overrides a skill (or the
user) asking for a plan or an explanation.
